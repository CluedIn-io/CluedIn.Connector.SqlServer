### Features
- Added SQL permission verification during connection testing. When a user explicitly tests a connection (not during automatic health checks), the connector now validates that the configured SQL user has all required permissions including: SELECT on INFORMATION_SCHEMA views, CREATE TABLE and CREATE TYPE at the database level, and ALTER, EXECUTE, SELECT, INSERT, UPDATE, DELETE on the target schema, as well as EXECUTE on sp_rename. This helps identify permission issues upfront rather than encountering errors during data export operations.
